How search, filters, breadcrumbs, and file types work

Search and file-type filters apply only to the folder currently open. Breadcrumbs move back through the current root. CSV means a table, JSON means structured machine-readable evidence, MD means a Markdown report, SQL is a stored definition displayed as text, and HTML is a generated report. Opening a file never executes its contents.

# Prompt — Styled Renderers Without Data Loss

Create presentable renderers.

Markdown:
- server-side safe rendering
- tables/code/headings/callouts

CSV:
- all columns
- paginated/chunked rows
- search/sort
- row ranges/counts
- raw download

JSON:
- formatted tree/pre
- raw view

TXT/LOG:
- monospace
- search
- optional line numbers
- raw view

SQL/T-SQL:
- formatted code
- line numbers
- raw/copy

Mermaid:
- render locally when dependency is bundled
- otherwise source + optional generated image

Do not delete/truncate/rewrite canonical evidence.

Every formatted view must provide access to original raw content.

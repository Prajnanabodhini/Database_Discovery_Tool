# Prompt — Presentation Quality

The UI must be polished and readable.

Design:
- responsive desktop-first layout
- persistent left navigation
- header with DB/run context
- summary cards
- clean tables
- badges for FACT/INFERENCE/UNKNOWN
- status colors
- severity badges
- sticky table headers
- search/filter controls
- breadcrumbs
- readable code blocks
- clear empty/error states
- print-friendly report pages

Do not use presentation formatting to hide data.

For large datasets use pagination/virtualization rather than truncation.

Provide a dark/light friendly CSS structure if practical, but functionality comes first.

# Prompt — Execute Discovery Through the HTML UI

Implement a controlled job manager.

HTML buttons:
- Dry Run
- Test Connection
- Metadata
- Metadata + Logic
- Safe Profile
- Full Read-Only
- Report
- Git Export

Never accept a raw shell command.

Each action maps to an internal function/service.

Allow one heavy discovery job at a time by default.

Show:
- job ID
- DB
- mode
- status
- stage
- progress
- timestamps
- warnings/errors
- log tail

Provide safe cancellation.

Sequential multi-database processing remains mandatory.

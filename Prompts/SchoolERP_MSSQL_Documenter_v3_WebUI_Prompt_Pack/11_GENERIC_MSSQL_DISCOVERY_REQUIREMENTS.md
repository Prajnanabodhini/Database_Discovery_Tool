# Prompt — Preserve Comprehensive MSSQL Discovery

Do not lose the original whole-database coverage.

For every configured DB collect safely:
- server/database metadata
- schemas
- tables/columns
- PK/FK
- constraints
- indexes
- storage size
- row estimates/exact flags
- shape
- column profiles
- masked samples
- views
- SPs
- functions
- triggers
- synonyms
- sequences
- computed columns
- extended properties
- Agent jobs metadata
- dependency edges
- lineage
- pipeline candidates
- cross-DB/server refs
- declared/inferred relationships
- cardinality/orphans
- data quality
- structural classifications
- duplicate/legacy candidates
- high-connectivity objects
- definitions and hashes
- manifests/checksums
- access limitations/errors

FACT, DATA_VALIDATION, INFERENCE and UNKNOWN remain separate.
